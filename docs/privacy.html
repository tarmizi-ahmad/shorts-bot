1. Who uses this app

Shorts-ai is a personal automation tool used only by its developer to publish videos to the developer's own YouTube channel (WhatHappenTodayNow). It is not offered to the public, and no other person signs in to or uses it.

2. Google user data we access

The app requests one permission, for the developer's own Google account only:

  • https://www.googleapis.com/auth/youtube.upload – to upload videos that the app generates to the developer's channel.

The app does not read the developer's or anyone else's YouTube videos, comments, subscribers, analytics, contacts, email or any other Google data. It does not access data belonging to other users.

3. What is stored, and where

  • OAuth refresh token – stored only as an encrypted secret in the developer's private GitHub Actions settings, used to upload videos. Never shared, sold or disclosed.
  • Operational records – a small private database stores the ID and title of topics already used and the ID of videos already published, to avoid repeats. It contains no personal data of any other person.
  • Generated videos – temporary files in the automation environment, deleted automatically after a short retention period.

4. Third-party services

To produce the videos, public history text (for example event descriptions from Wikipedia) is sent to AI text and image services. No Google user data and no personal data is sent to them. YouTube data is never used to train AI models.

5. Use, sharing and Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not sold, not shared with third parties, not used for advertising, and not read by humans.

The app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service and the Google Privacy Policy.

6. Revoking access & deletion

Access can be revoked at any time at myaccount.google.com/permissions. After revocation the stored token stops working and is deleted from the automation settings. To request deletion of any stored record, email the address below.

7. Changes & contact
